# Archived Scripts

This directory contains supporting scripts used during project development.

- Metadata and temporal-sequence inspection
- Dataset download and cache verification
- Multispectral image and tensor validation
- Training smoke tests and performance benchmarks
- Class-imbalance and feature-cache inspection

These scripts are retained for development history and reproducibility. The primary workflow and model experiments remain in the parent `scripts/` directory.

Note: Some archived scripts may require path adjustments before they can be executed from this directory.
